Настройка

Параметры secrets.yml

При сохранении обновляются только изменённые поля. Неизвестные параметры, вложенные настройки, исходные типы YAML и дополнительные комментарии сохраняются.

1. Сеть и пользователи
IP и Linux-пользователь нужны только для тех серверов, которые входят в выбранный сценарий. Пароли bootstrap требуются при полном развёртывании; если root-пароль задан и подходит для первичного входа, SSH/sudo-поля можно оставить пустыми.
2. Глобальные параметры
Домен и email обязательны для сценариев с локальным Workload/Certbot; для VPS-only можно оставить пустыми.
3. Уведомления Telegram
Требуется для сценариев с VPS/Edge (Alertmanager). Для local-only можно оставить пустым.
Требуется вместе с токеном Telegram для VPS/Edge; для local-only можно оставить пустым.
4. Интеграция с DNS
Требуется для local-сценариев, где Certbot выпускает сертификаты через DNS-01. Для VPS-only можно оставить пустым.
5. Настройки СУБД PostgreSQL и Redis
6. Безопасность и бэкапы
Необязательно. Не меняйте после первого запуска AdGuard Home.
Пары проверяются на соответствие. Для сценариев без bootstrap выберите ключ, чей публичный аналог уже разрешён на целевых серверах.
Необязательный параметр. Заполняйте только при наличии отдельного диска для локального Borg-репозитория.
7. Hermes Agent (API и панель Edge)
Адрес API провайдера, включая /v1 при необходимости.
Ключ нельзя сгенерировать локально. Обязателен для сценариев с VPS/Edge; для локального сервера не используется.

🎉 Деплой завершён — что дальше

                        
Несколько финальных шагов настройки и шпаргалка по сервисам. Разверните нужный раздел.

                    


                    

                        

                            📦 Проверка резервных копий
                            

                                
    
                                    
  1. Проверьте расписание резервного копирования: systemctl status borgmatic.timer.
    2. 
                                    
  2. Проверьте журнал резервного копирования и S3: sudo journalctl -u borgmatic.service --since today.
    3. 
                                    
  3. Проверьте Prometheus-метрики servehub_borgmatic_backup_last_run_success и servehub_offsite_backup_last_run_success.
    4. 
                                    
  4. Храните borgmatic_encryption_passphrase отдельно от серверов и S3. Без парольной фразы восстановить шифрованные архивы нельзя.
    5. 
                                    
  5. Инструкция по восстановлению: docs/BACKUPS.md в репозитории.
    6. 
                                

                            

                        


                        

                            🔌 Автономность локального сервера
                            

                                
    
                                    
  1. Чтобы сервер включался обратно после отключения электричества, в BIOS нужно найти следующие настройки (названия могут отличаться в зависимости от производителя):
                                        
      
                                            
    1. State After G3: выбрать S0 State.
      2. 
                                            
    2. Wake system from S5: Disabled.
      3. 
                                        
    
                                    
    2. 
                                

                            

                        


                        

                            🚀 Пользование сервисами
                            

                                
    
                                    
  1. Вход на портал: после успешного запуска перейдите по вашему домену на главную страницу (веб-портал), предварительно включив VPN-клиент AmneziaWG на вашем устройстве.
    2. 
                                    
  2. Первичная настройка приложений: для сервисов Navidrome, Audiobookshelf, Vaultwarden, Gitea при первом открытии необходимо пройти быструю процедуру создания аккаунта администратора. Для доступа к системной панели администрирования Vaultwarden используется токен, заданный в переменной secret_vaultwarden_password.
    3. 
                                    
  3. Автоматическое развёртывание: сервисы Nextcloud, Grafana и другие настраиваются автоматически. Данные для первого входа в них соответствуют глобальным переменным admin_user и admin_password из вашего secrets.yml.
    4. 
                                    
  4. Рекомендованные приложения для повседневного использования:
                                        
      
                                            
    • Облачное хранилище — Nextcloud
      • 
                                            
    • Менеджер паролей — Bitwarden
      • 
                                            
    • Управление DNS-сервером — AdGuard Home Manager
      • 
                                            
    • Музыкальная коллекция — Tempo
      • 
                                            
    • Аудиокниги и подкасты — Audiobookshelf
      • 
                                            
    • VPN-клиент — AmneziaWG / WG Tunnel
      • 
                                        
    
                                    
    5. 
                                    
  5. Прямое подключение по SSH внутри защищённого VPN-туннеля:
                                        
      
                                            
    • К удалённому серверу (VPS): ssh user@10.8.0.1
      • 
                                            
    • К локальному серверу: ssh user@10.8.0.2
      • 
                                        
    
                                        
    Эти приватные IP-адреса будут доступны только тогда, когда на вашем рабочем устройстве запущен и активен VPN-клиент AmneziaWG.
    
                                    
    6. 
                                    
  6. Использование папок (при переносе проекта главное — скопировать эти папки):
                                        
      
                                            
    • В папке ~/ServeHub-2/apps-data (есть как на локальном, так и на удалённом серверах) хранятся данные приложений. При переносе проекта её важно сохранить.
      • 
                                            
    • В папке ~/PersonalData хранятся все пользовательские данные: документы, фото, видео, музыка и т.д.
      •
