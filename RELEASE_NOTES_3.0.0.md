# ServeHub-2 3.0.0 — заметки к выпуску

Версия 3.0.0 — крупное обновление архитектуры и процесса развёртывания. Ниже перечислены основные изменения относительно прежней версии проекта, находившейся в ветке `main`.

## Основные изменения

- **Новая двухузловая архитектура Edge / Workload.** Edge/VPS обеспечивает VPN, DNS-фильтрацию, мониторинг и оповещения; Workload запускает пользовательские приложения, хранит постоянные данные и предоставляет веб-доступ через Nginx и TLS.
- **Поддерживается только Ubuntu Server 24.04 LTS.** Поддержка Debian и Arch Linux удалена из целевого сценария.
- **Hermes Agent интегрирован в Edge и стал обязательным компонентом.** Его панель доступна через VPN/HTTPS, состояние сохраняется в `apps-data/hermes/`, а пользовательская рабочая папка `apps-data/hermes-workspace/` монтируется как `/workspace`. Для запуска требуется совместимый API endpoint, ключ, модель и секрет Dashboard.
- **Добавлен Actual Budget** для локального управления бюджетом с постоянными данными в `apps-data/actual-budget/`.
- **Переработан мониторинг доступности.** Gatus удалён; проверки HTTP/TLS выполняются через Prometheus и Blackbox Exporter. Добавлен Grafana dashboard для доступности сервисов.
- **Переработано резервное копирование.** Borg/Borgmatic создаёт зашифрованные локальные репозитории, а rclone зеркалирует их в отдельные S3-префиксы для Edge и Workload. Добавлены проверки безопасности назначения, сверка размеров объектов, метрики полной цепочки, алерты и Grafana dashboard статуса бэкапов.
- **Обновлена веб-архитектура.** Конфигурация Nginx сведена к общему шаблону для сервисных поддоменов; Certbot использует DNS-01 через Webnames на Workload.
- **Усилено развёртывание и безопасность.** Переработаны bootstrap и проверки предварительных условий; правила firewall учитывают Docker DNAT через `DOCKER-USER`, сохранена интеграция с Fail2ban. Проверяются параметры секретов, конфигурации Compose/Ansible и правила мониторинга.
- **Обновлён GUI-установщик.** Можно выбрать опубликованный релиз, Git-тег или `dev`; выбранная версия закрепляется по commit SHA. Добавлены проверки каталога установки, целостности загружаемого проекта и конфигурации секретов.
- **Добавлены автоматизированные CI-проверки** секретов, YAML/Ansible, Compose, firewall, правил Prometheus, исходных зависимостей и контейнерных образов.

## Удалённые или заменённые компоненты

- **Gatus** заменён мониторингом Prometheus + Blackbox Exporter и Grafana dashboard.
- **BorgUI** заменён Grafana dashboard статуса резервного копирования и метриками Borgmatic.
- **Portainer и Portainer Agent** больше не входят в текущие Compose-стеки.
- Отдельный Compose-файл для VPN-подключения необязательного Hermes больше не является способом его развёртывания: Hermes запускается как обязательный сервис Edge.

## Совместимость и важные ограничения

- **Миграция со старых версий официально не поддерживается.** Ручной переход технически возможен и был опробован автором, но не автоматизирован и не гарантирует совместимость конфигураций, данных приложений и резервных копий. Рекомендуется новая установка на чистые Ubuntu Server 24.04 LTS и выборочный перенос данных после проверки.
- **Резервное копирование вызывает временную недоступность сервисов.** Во время создания локального Borg-архива Compose-сервисы, кроме перечисленных в конфигурации исключений, останавливаются и затем запускаются повторно. На Edge это влияет в том числе на VPN и мониторинг.
- **S3-копия является зеркалом, а не независимым неизменяемым архивом.** `rclone sync` отражает удаления локального репозитория. Проверка `--size-only` сверяет наличие файлов и размеры, но не заменяет тест восстановления. Проверяйте восстановление данных и храните парольную фразу Borg отдельно от серверов и S3.
- **Перед реальной эксплуатацией проверьте** VPN, DNS/TLS, доступ к приложениям, Prometheus targets, доставку алертов и восстановление обеих резервных копий.

Подробности установки, эксплуатации и восстановления находятся в [индексе документации](docs/README.md).
