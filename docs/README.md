## Перед началом

Проект ориентирован на Ubuntu Server 24.04 LTS и двухузловую схему Edge/VPS + Workload. Установка изменяет сетевые правила, SSH и Docker, поэтому сначала используйте чистые виртуальные машины и обеспечьте доступ к консоли VPS.

Документация не заменяет проверку реального развёртывания. Отдельно проверьте работу приложений, VPN-доступ, получение TLS-сертификатов, доставку алертов и восстановление данных из резервной копии.
