## Перед началом

Проект ориентирован на Ubuntu Server 24.04 LTS и двухузловую схему Edge/VPS + Workload. Перед развёртыванием подготовьте DNS/Webnames, Telegram (если нужны алерты), приватный S3-бакет и секреты. Установка меняет сетевые правила, SSH и Docker, поэтому сначала используйте чистые виртуальные машины и обеспечьте доступ к консоли VPS.

Подробный список предварительных требований, настройка тестовых VM и сборка GUI-установщика находятся в [руководстве по установке](INSTALLATION.md). Отдельно проверьте работу приложений, VPN-доступ, получение TLS-сертификатов, доставку алертов и восстановление данных из резервной копии.
