# Безопасность и границы доверия

## Секреты

Не коммитьте `ansible/vars/secrets.yml`, приватные SSH-ключи, `.env`, Webnames API key, Telegram token, S3 credentials или парольную фразу Borg. Для `secrets.yml` используйте права `0600`. Атомарная запись установщика не шифрует файл. GUI работает с обычным YAML; Ansible Vault не поддерживается сквозным процессом редактирования и деплоя.

S3-конфигурация на серверах хранится в `/etc/servehub/rclone.conf` и должна быть доступна только root. Не вставляйте секреты в логи, issues и публичные файлы.

## Привилегии SSH/Docker

Пользователь развёртывания входит в группу `docker`; доступ к Docker на Linux практически равнозначен root. Рассматривайте эту учётную запись как административную. Используйте отдельный SSH deploy-ключ. Ansible принимает неизвестный host key при первом подключении через `StrictHostKeyChecking accept-new`, но смену уже известного ключа следует расследовать через доверенный канал.

## Firewall и VPN

Edge предназначен для SSH-администрирования и входящего UDP 51820 для VPN. Nginx и правила firewall ограничивают доступ к сервисам VPN-подсетью. Не публикуйте TCP 51821 (wg-easy UI и endpoint метрик) в интернет: конфигурация wg-easy допускает HTTP, поэтому административная панель должна идти через HTTPS reverse proxy внутри VPN. Если включаете Bearer Password для метрик, настройте авторизацию в scrape job Prometheus и не коммитьте пароль или токен. Не удаляйте цепочки Fail2ban и не меняйте `DOCKER-USER` без понимания маршрутизации. Перед изменениями обеспечьте доступ к консоли VPS.

## Hermes

Hermes имеет доступ к конфигурации, инструментам и `/workspace`. Любой файл в `apps-data/hermes-workspace/` следует считать доступным агенту; не размещайте там приватные SSH-ключи, API-токены и другие секреты без явной необходимости. Для внешнего доступа к серверам используйте отдельные ключи с минимальными правами и предоставляйте их только через явно настроенный, ограниченный путь.

Запросы и содержимое файлов, переданные модели, могут отправляться настроенному API-провайдеру; проверьте его условия обработки данных и не передавайте чувствительное содержимое без оценки риска. Текущий Compose не монтирует Docker socket внутрь Hermes. Не включайте privileged-режим и не добавляйте `/var/run/docker.sock` ради доступа к терминалу: доступ к Docker daemon практически эквивалентен root на хосте. Dashboard защищён Basic Auth и должен быть доступен через VPN/HTTPS; не публикуйте порт 9119.

## Резервные копии

Borg шифрует архивы, но S3-ключи дают возможность читать, записывать и удалять объекты. Используйте отдельный ключ с минимальными правами. `rclone sync` отражает удаления, поэтому S3-зеркало не защищает от всех сценариев потери данных. Пароль Borg храните отдельно от серверов и S3. Проверка размеров объектов не заменяет тест восстановления. См. [BACKUPS.md](BACKUPS.md).
